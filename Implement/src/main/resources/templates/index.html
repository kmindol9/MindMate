AI Decision Support System

MindMate

MindMate는 혼자 정리하기 어려운 고민과 선택 상황을
감정, 문제 유형, 핵심 원인, 현실적인 대안으로 나누어 분석하는 의사결정 지원 시스템입니다.

MindMate는 사용자의 결정을 대신하지 않습니다. 대신 현재 상황을 객관적으로 정리하고, 스스로 판단할 수 있도록 돕는 것을 목표로 합니다.

MindMate가 제공하는 지원 방식

고민 분석

학업, 진로, 인간관계, 비교 불안처럼 복잡한 고민을 감정과 원인 중심으로 정리합니다.

간단 의사결정

일상적인 선택이나 가벼운 고민을 장단점, 판단 기준, 현실적인 선택 방향으로 분석합니다.

문제 구조화

막연한 고민을 감정 분석, 문제 유형, 핵심 원인, 객관적 관점, 대안으로 나누어 보여줍니다.

근거 기반 피드백

단순한 위로가 아니라 통계 및 사례 데이터를 함께 제공하여 현실적인 판단을 지원합니다.

기본 분석 모드

외부 AI 서버가 불안정한 경우에도 MindMate 내부 기준을 바탕으로 예비 분석 결과를 제공합니다.

기록 비저장 원칙

입력 내용은 기본적으로 서버에 저장되지 않으며, 작성 중인 내용은 현재 탭 안에서만 임시 유지됩니다.
