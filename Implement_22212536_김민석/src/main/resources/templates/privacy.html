Privacy First

개인정보 안내

MindMate는 사용자의 고민과 선택 내용을 민감한 정보로 보고,
기본적으로 내용을 저장하지 않는 방향으로 설계되었습니다.

사용자의 입력 내용은 분석을 위해 일시적으로 사용되며, 별도의 저장 기능을 선택하지 않는 한 서버 데이터베이스에 기록되지 않습니다.

MindMate의 기록 처리 원칙

기본값: 저장하지 않음

사용자가 입력한 고민이나 선택 내용은 기본적으로 서버에 저장하지 않습니다. MindMate는 사용자의 사적인 고민을 불필요하게 기록하지 않는 것을 원칙으로 합니다.

현재 탭에서만 임시 유지

분석 실패나 새로고침 상황을 대비해 작성 중인 내용은 현재 브라우저 탭 안에서만 임시로 유지됩니다. 이는 사용자가 같은 내용을 반복해서 입력하지 않도록 돕기 위한 목적입니다.

탭을 닫으면 사라짐

임시 입력 내용은 sessionStorage를 사용하므로, 브라우저 탭을 닫으면 사라집니다. 이는 장기 저장을 피하고 사용자의 부담을 줄이기 위한 방식입니다.

선택적 저장 원칙

향후 기록 기능을 추가하더라도, 사용자가 명시적으로 저장을 선택한 경우에만 기록하도록 확장할 수 있습니다. 기본 설정은 항상 저장하지 않는 방향을 유지합니다.

의사결정 보조 목적

MindMate는 사용자의 결정을 대신하지 않습니다. 입력 내용을 바탕으로 상황을 정리하고, 사용자가 스스로 판단할 수 있도록 돕는 보조 시스템입니다.

외부 AI 사용 안내

MindMate는 분석을 위해 외부 AI API를 사용할 수 있습니다. 외부 AI 서버가 불안정한 경우에는 내부 기준을 바탕으로 기본 분석 모드를 제공합니다.
